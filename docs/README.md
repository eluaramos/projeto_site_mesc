# Documentação do Projeto — MESC UFF

## Estrutura

- features/      — Specs e planos de implementação por funcionalidade
- architecture/  — Diagramas e decisões de arquitetura (ADR)
- prototypes/    — Protótipos HTML estáticos iniciais (referência)

## Convenções

- Planos de feature: features/nome-plano.md
- Specs de design: features/nome-spec.md
- Decisões de arquitetura: architecture/adr-numero-titulo.md

## Atenção

Os arquivos em features/pagina-contato-* foram criados antes da migração
de Bootstrap para Tailwind CSS. Antes de implementar, atualizar as
referências a classes Bootstrap para Tailwind.
